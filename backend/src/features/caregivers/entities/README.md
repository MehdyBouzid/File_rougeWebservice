# Entités TypeORM

Décrire ici les classes persistées et leurs relations, à partir du modèle validé.
Le registre reconnaît les fichiers `*.entity.ts` avec un import nommé de `Entity` depuis `typeorm` ; une connexion reste à configurer.
La classe fournie reste sans décorateur tant que ses colonnes et sa clé primaire ne sont pas définies ; elle n’est donc pas enregistrée par TypeORM.
