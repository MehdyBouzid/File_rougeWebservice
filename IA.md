# Usage de l'IA

## Outil utilisé

- **Claude Code** (Anthropic)

## Périmètre

Claude Code a été utilisé uniquement pour l'initialisation technique du projet :

- génération du backend avec Spring Initializr (structure par défaut, sans code métier) ;
- génération du frontend avec le CLI Ionic (starter `blank`, Angular, Capacitor) ;
- rédaction du `README.md` et de ce fichier.

Aucune fonctionnalité métier, entité, API, configuration de base de données ou d'authentification n'a été produite par l'IA.
