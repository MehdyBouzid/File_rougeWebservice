# Usage de l'IA

Claude Code a été utilisé pour :

- installer et initialiser le projet Java Spring Boot ;
- mettre en place l'architecture de dossiers du projet ;
- écrire la documentation (`README.md`, `docs/design.md`, `docs/http.md`) ;
- pour le TP1 : vérifier les outils sur le poste de Mehdy, exécuter les requêtes curl de l'exploration HTTP, créer la collection `bruno/` et le `.gitignore` racine.

Les choix de conception, les décisions métier et le MCD restent sous la responsabilité de l'équipe.
